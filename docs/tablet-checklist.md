## All of grade 1 (ch. 1-64)

Before you start, note the chapter the class is at: ______. Then, on the parent screen, under «Μέχρι πού έχει φτάσει η τάξη», set the chapter to 64 so every chapter's exercises can come up. To reach a particular chapter sooner, set it to that chapter instead. **When you finish, set it back to the class's chapter.** Testing at 64 leaves answers in the progress; if you want a clean start, use «Σβήσιμο προόδου» afterwards (stars and the Workshop stay).

Date: ____________

| # | Check | How | ✓ |
| --- | --- | --- | --- |
| 1 | The update arrives calmly | Open the app on the start screen. A new version is applied there or from the parent screen, never in the middle of a round. | |
| 2 | Tens and units (ch. 33-39) | Build a number with rods and cubes. Tie 10 cubes into a rod. Read the number in the place-value table. Every tap target is big enough for a finger. | |
| 3 | Through ten, 2-digit ± 1-digit (ch. 42-50) | The ten frames sit side by side. The hints are about «κάνω δέκα». In subtraction the clip says «μείον», not «πλην». | |
| 4 | Time (ch. 41) | Put the pictures of a story in order: first, last, in the middle. Fill in yesterday and tomorrow on the calendar cards. Pick the tree of the right season. On the month calendar, find the circled date's day on the cards below: the columns line up with the cards in portrait and in landscape. | |
| 5 | Picture answers, first time | The first time an answer is a picture to tap (pictures, the week, the scale), the tiles light up one after another with the clip «Δες πώς απαντάς εδώ…», then the question is read. It does not happen again. | |
| 6 | To 100, money, groups (ch. 52-62) | Paper clips, ten more or less, the wallet with notes and coins, sharing onto plates, the heavier pan. | |
| 7 | Shapes and space (part 4) | Which shape, counting triangles, taller and shorter, patterns, arrows, routes round rocks, pieces of a shape, mirror halves. | |
| 8 | Word problems | They are read aloud whole, in Eleni's voice. Text appears only if every word is one the child can read. | |
| 9 | «Δεν ξέρω ακόμα» | Tap it. The worked example is shown with its answer, and then a similar question comes. No star is lost, and nothing negative is said. | |
| 10 | Calm pause | Tap three wrong answers fast. The breathing circle and the hedgehog appear, then the question is read again. No clock, no number of seconds, no red. | |
| 11 | Workshop rooms | Spend stars. When a room is full, the child moves to the next one and its clip plays. The arrows let you visit the full rooms. Items in later rooms cost more stars. | |
| 12 | Home cards | Parent screen → «Δραστηριότητες για το σπίτι». The cards up to the chapter you set are listed, the newest first. «Γράφουμε τους αριθμούς» (ch. 6) and «Φωτογραφίες και ημερολόγιο» (ch. 41) are among them. A ✓ stays after you close and reopen the app. | |
| 13 | Teacher section | Parent screen → «Για συζήτηση με τη δασκάλα». After a few days of play it says «Δεν υπάρχει κάτι να σημειωθεί.» (it needs three weeks of answers before it says anything else). | |
| 14 | Offline again | Airplane mode, open from the home screen, play a session with sound: every new clip plays. | |
| 15 | Back to the class's chapter | «Μέχρι πού έχει φτάσει η τάξη» is set back to the chapter noted at the top. | |
